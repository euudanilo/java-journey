# 📘 Dia 003 - As Três Operações Básicas de Programação

## 🎯 Objetivo

Compreender quais são as três operações fundamentais presentes em praticamente todo programa de computador.

---

# 📚 Resumo

Todo programa de computador é capaz de realizar três operações básicas:

1. Entrada de dados (Leitura)
2. Processamento de dados
3. Saída de dados (Escrita)

Essas operações formam a base da programação e estarão presentes em praticamente qualquer sistema desenvolvido.

---

# 📖 Conteúdo aprendido

## 📥 Entrada de Dados (Leitura)

É o momento em que o usuário fornece informações para o programa.

Esses dados normalmente são inseridos através de dispositivos de entrada, como:

- Teclado
- Mouse
- Scanner
- Arquivos

Os valores informados são armazenados em variáveis para serem utilizados posteriormente.

Exemplo:

```text
Digite seu nome:
Danilo
```

O programa realizou uma leitura de dados.

---

## ⚙️ Processamento de Dados

Após receber os dados, o programa realiza algum processamento.

Esse processamento acontece dentro do processador do computador e consiste na execução de cálculos, comparações e operações lógicas.

Normalmente, o resultado é armazenado em uma variável por meio de uma atribuição.

Exemplo:

```java
int soma = numero1 + numero2;
```

Nesse caso:

- A expressão é calculada.
- O resultado é armazenado na variável `soma`.

---

## 📤 Saída de Dados (Escrita)

Depois de processar as informações, o programa apresenta o resultado ao usuário.

Essa operação recebe o nome de escrita ou saída de dados.

Ela geralmente acontece por meio de dispositivos como:

- Monitor
- Impressora
- Arquivos

Exemplo:

```text
Resultado: 25
```

---

# 📝 Conceitos importantes

- Entrada de dados = Leitura
- Processamento = Execução de cálculos
- Saída de dados = Escrita

Fluxo básico de um programa:

```text
Entrada
     ↓
Processamento
     ↓
Saída
```
