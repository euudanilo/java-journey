# Dia 003 — As Três Operações Básicas de Programação

## Conteúdo

Nesta aula foi apresentada uma visão geral das três operações básicas que um programa de computador pode realizar:

- Entrada de dados
- Processamento de dados
- Saída de dados

Essas três operações formam uma visão geral do funcionamento de um programa.

## Entrada de Dados

A entrada de dados acontece quando o usuário informa dados para o programa.

Esses dados são armazenados dentro de variáveis.

Um exemplo de dispositivo utilizado para entrada de dados é o teclado.

A entrada de dados também pode ser chamada de **leitura**, pois o programa está lendo os dados informados pelo usuário.

```text
Usuário
   ↓
Entrada de dados
   ↓
Variáveis
```

## Processamento de Dados

O processamento de dados acontece quando o programa realiza operações ou cálculos utilizando os dados recebidos.

O processamento ocorre dentro do processador.

Nesta etapa, é utilizado um comando chamado atribuição, que indica que uma determinada variável receberá o resultado de uma expressão.

Exemplo conceitual:

```text
variável ← resultado de uma expressão
```

O comando de atribuição será estudado com mais detalhes posteriormente.

## Saída de Dados

A saída de dados acontece quando o programa informa dados para o usuário.

Um exemplo de dispositivo utilizado para saída de dados é o monitor.

A saída de dados também pode ser chamada de **escrita**, pois o programa está escrevendo ou apresentando informações para o usuário.

```text
Processamento
      ↓
Saída de dados
      ↓
   Usuário
```

## As Três Operações

As três operações básicas podem ser representadas da seguinte forma:

```text
Entrada
   ↓
Processamento
   ↓
Saída
```

### Entrada

O usuário fornece dados para o programa.

Também chamada de:

```text
Leitura
```

### Processamento

O programa realiza operações e cálculos utilizando os dados.

### Saída

O programa apresenta informações para o usuário.

Também chamada de:

```text
Escrita
```
