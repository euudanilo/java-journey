# 📖 Sobre

Bem-vindo ao meu **Java Journey**!

Este repositório documenta toda a minha evolução durante o curso **Java COMPLETO - Programação Orientada a Objetos + Projetos**, ministrado pelo professor Nélio Alves.

Meu objetivo é construir uma base sólida em Java, dominar Programação Orientada a Objetos (POO), desenvolver projetos práticos e registrar minha evolução ao longo da jornada de aprendizado.

Mais do que concluir um curso, este repositório representa meu compromisso com a prática diária e com a construção de um portfólio público.

---

- Aprender Java do básico ao avançado
- Dominar Programação Orientada a Objetos (POO)
